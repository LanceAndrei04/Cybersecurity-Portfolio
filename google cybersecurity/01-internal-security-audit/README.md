# Internal Security Audit — Botium Toys

> Google Cybersecurity Professional Certificate — Portfolio Activity

## Overview

This activity involved conducting an internal security audit for **Botium Toys**, a fictional company used in the Google Cybersecurity Professional Certificate.

The goal was to review the organization’s current security posture, identify missing or weak controls, and assess compliance-related gaps.

## Scenario

Botium Toys is expanding its online operations and processes customer and payment information.

The organization currently has a high risk score due to gaps in security controls, asset management, and compliance practices.

## What I Did

I reviewed the provided:

- Audit scope and goals
- Current IT assets
- Risk assessment
- Existing security controls
- Compliance requirements

I then completed a controls and compliance checklist covering:

- Access controls
- Network and endpoint security
- Data protection
- Business continuity
- PCI DSS
- GDPR
- SOC controls

## Key Findings

Some security controls were already implemented, including:

- Firewall
- Antivirus
- Physical locks
- CCTV
- Fire detection and prevention
- Data integrity controls

However, several important gaps were identified:

- Least privilege was not implemented
- Separation of duties was not implemented
- Customer and payment data was not encrypted
- No intrusion detection system was deployed
- No disaster recovery plan was in place
- Critical data was not backed up
- Password management controls were weak
- Sensitive data access was too broad

## Recommendations

The following actions were prioritized based on the identified risks:

1. **Strengthen access controls** by implementing least privilege and separation of duties.

2. **Protect sensitive data** by enabling encryption, strengthening password policies, and implementing centralized password management.

3. **Improve business continuity** by establishing regular backups and creating a disaster recovery plan.

4. **Improve detection capabilities** by deploying an intrusion detection system and formalizing legacy-system monitoring.

5. **Improve compliance posture** by securing payment-card information and maintaining proper asset and data classification practices.

## Key Takeaway

This activity helped me understand the difference between a control being **present** and a control being **effective**.

For example, Botium Toys had an existing password policy, but its requirements were weak. This showed me that security analysis requires looking beyond whether a control exists and evaluating whether it adequately reduces risk.
